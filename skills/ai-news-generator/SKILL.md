# AI News Generator

AI関連ニュースを「1ネタ=1 Markdownファイル」で蓄積し、同時に月次サマリーも更新する。専門用語は避け、読者が「何が起きたか」「生活や仕事にどう関係するか」をすぐ理解できる形で書く。

## 対象にするニュース

次のいずれかに当てはまる話題を扱う。

1. AIの新機能・新サービス
2. AIと仕事・生活の活用事例
3. AIの社会的影響、規制、提携、買収、問題点

ネタ種別は内部判断に留め、ファイル名や本文には書かない。

## 作成ルール

- 記事ファイル名は `YYYY-MM-DD_[親しみやすい日本語タイトル].md` にする。
- 保存先は `source/YYYY-MM/` にする。必要ならディレクトリを作る。
- 記事を新規作成または更新したら、同じターンで `source/YYYY-MM/summary.md` も更新する。
- 月次サマリー更新時は、その月の `.md` 記事を走査し、`summary.md` 自身は除外する。
- 同じトピックで続報がある場合は、既存記事に統合できるかを先に確認する。

## 記事の書き方

- 読者はAIの専門知識がない一般ビジネスパーソンを想定する。
- 難しい原文はそのまま貼らず、日本語で意訳して説明する。
- 技術の仕組みより、「何ができるようになったか」「何がすごいか」「何が変わるか」を優先する。
- 専門用語を使うときは、その場で中学生でも分かる説明を付ける。
- 事実と推測を分け、曖昧な断定やぼかし表現を増やしすぎない。
- 英語タイトルをそのまま見出しに使わず、日本語の親しみやすいタイトルにする。

## 記事テンプレート

```markdown
# [親しみやすい日本語タイトル]

## 日付: YYYY-MM-DD

### ソース
- **[メディア名]**: [記事タイトル](URL)

### 3行でわかる要約
- [ポイント1]
- [ポイント2]
- [ポイント3]

### 詳しく解説
[300-500文字程度で分かりやすく解説する]

### 知っておきたいキーワード
- **[用語]**: [やさしい解説]

### 私たちの生活への影響・メリット
[生活や仕事への関係を自分事として書く]
```

## 月次サマリーの書き方

- ファイル名は `source/YYYY-MM/summary.md` にする。
- `この月のポイント` は、その月に共通する重要トレンドを3-5件書く。
- `記事一覧` は日付の新しい順、同日内はファイル名順に並べる。
- 各記事の一言要約は、記事本文の `3行でわかる要約` と `私たちの生活への影響・メリット` をもとに、初心者向けに1-2文で書き直す。
- サマリーにはソースURLを載せず、その月フォルダ内の記事へのリンクだけを載せる。
- 記事が増えたときは差分追加で済ませず、`summary.md` 全体を見直す。

## 月次サマリーテンプレート

```markdown
# YYYY年M月 AIニュースまとめ

## この月のポイント
- [月全体の重要トレンド1]
- [月全体の重要トレンド2]
- [月全体の重要トレンド3]

## 記事一覧

### YYYY-MM-DD
- [記事タイトル](YYYY-MM-DD_タイトル.md): わかりやすい短い要約
```

## 禁止事項

- 専門用語を説明なしで使う
- 英語記事タイトルをそのまま載せる
- 表形式でまとめる
- 記事だけ作って `summary.md` を更新せずに終える
- 「と思われる」「の模様」などの曖昧表現に頼りすぎる
